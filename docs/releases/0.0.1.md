# Forge 0.0.1

Forge is a Windows workspace for project files, diagrams, checklists, datasets and web references.

- Organize project resources in Space. Add files, create cards and connect sources to analyses.
- Use Gallery, Palette, Metadata and Comparison with saved source versions. Gallery plays qualified WebM and MP4 profiles. Comparison handles document text and matching-size image differences.
- Draw diagrams in Scheme, track preparation in Checklist and import CSV or TSV in Dataset.
- Browse an HTTPS reference in a separate Site profile and explicitly save a link and quote.
- Save sourced excerpts and audio transcripts in Research. In Intelligent, review the exact input before using a local model provider.
- Use Editor to save an image recipe and export a separate PNG or JPEG. Use Git to review and commit local changes and switch branches from a clean working tree.
- Edit a writable DOCX or PDF copy in a qualified Windows application and import it as a new version.
- Export and restore project and application settings backups through Settings.
- Install verified updates and roll back to the previous version with the update backup from Settings.
