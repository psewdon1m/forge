# Forge 0.0.3

This candidate includes the Scheme drag and pan qualification fix from 0.0.2 and two Windows fixes.

- Directory rejects rename, move and delete requests that use an outdated file version even after a same-size rewrite preserves the modified timestamp. It uses the filesystem change sequence when available and verifies the file contents on volumes without one.
- The Windows installation test waits for Electron to create its window before driving the installed app.
- Updated the Rust URL parser to 2.5.9 to incorporate [the upstream security fix](https://github.com/servo/rust-url/security/advisories/GHSA-hrj5-67jp-wqp9).
