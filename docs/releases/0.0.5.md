# Forge 0.0.5

The Windows installer now opens a setup wizard. Choose the destination folder and Start menu group, add a desktop shortcut if desired, and launch Forge when Setup finishes. The installer works offline. Running it again restores the files of the same release and keeps your settings and rollback history.

Existing installations can update from **Settings → Updates**. For a new installation, download the versioned `Forge-Installer` executable from the release assets.

Forge uses the anvil icon in its window, taskbar, notification area, launcher and shortcuts. **Settings → Uninstall** removes the program and local application data while retaining project folders and backups.
